# CASE 17

لعبة تحقيق عربية تعتمد حاليًا على **20 قضية كلاسيكية** مقتبسة ومُعاد صياغتها كلعبة استنتاج، بدل القضايا المولدة السابقة.

- 5 قضايا سهل.
- 5 قضايا متوسط.
- 5 قضايا صعب.
- 5 قضايا خبير.
- جميع القضايا مقفلة بالتسلسل؛ حل القضية الحالية يفتح التالية.
- أسماء وإفادات وأدلة مرتبطة بالشخصيات داخل كل قضية.
- المصدر الأصلي لا يظهر داخل القضية إلا بعد حلها حتى لا يحرق اللغز.
- التقدم محفوظ محليًا على الجهاز.
- مصممة للهاتف وGitHub Pages.

## المصادر الأدبية

الحبكات الحالية مُعاد صياغتها من أعمال تحقيق كلاسيكية في الملكية العامة، وأبرزها:

- Arthur Conan Doyle — The Adventures of Sherlock Holmes
- Arthur Conan Doyle — The Memoirs of Sherlock Holmes
- Arthur Conan Doyle — The Return of Sherlock Holmes
- G. K. Chesterton — The Innocence of Father Brown

الروابط الأصلية محفوظة داخل بيانات كل قضية وتظهر للاعب بعد الحل.
